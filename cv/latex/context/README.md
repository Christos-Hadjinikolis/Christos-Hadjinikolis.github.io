# CV Context

Private working context for CV and website positioning. These notes and evidence files are source material, not publishable copy.

## Structure

- `baseline/` - consolidated career context and factual evidence used across CV variants.
- `positioning/` - narrative decisions, role-framing reports, and future copy candidates.
- `raw/` - private source material preserved close to its original form.
- `evidence/` - private screenshots and other supporting artefacts.

## Publication Boundary

`cv/latex/cv.tex` and website pages can use externally safe claims derived from this folder. Do not copy raw feedback, screenshots, self-evaluations, Jira or Confluence excerpts, Slack quotes, or company operational detail directly into public copy.
