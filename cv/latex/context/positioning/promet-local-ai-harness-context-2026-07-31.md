## What Promet Is

Promet is a local-first AI workbench / harness shell for building memory-aware, voice-enabled, tool-using assistants that run on a user's own machine.

Repo evidence:

- `../promet-src/README.md` describes Promet as a local-first AI workbench for memory-aware, voice-enabled, tool-using assistants.
- `../promet-src/AGENTS.md` states that the harness is the product: context ownership, approvals, streaming, memory boundaries, tools, traceability, and interface behaviour matter as much as model access.
- `../promet-src/pyproject.toml` defines the package description as a local-first AI workbench for building memory-aware, tool-using agents, with a `promet` CLI.

User-confirmed context:

- The user's intended shorthand is: local AI harness shell.

## Relevant Capabilities

Promet demonstrates hands-on work on the engineering system around LLMs/agents rather than merely calling an LLM API:

- local model runtime support through LM Studio / Ollama-style adapters;
- package-owned CLI setup, launch, runtime/model selection, diagnostics, and local macOS app bundling;
- FastAPI local application shell and browser UI;
- durable local thread/project state using SQLite;
- streaming chat and interactive voice runtime boundaries;
- tool registry, schema validation, side-effect policy, approval gates, audit records, and deterministic fallbacks;
- MCP as a pluggable connector/discovery mechanism, not as the safety model;
- prompt-source authority separation between user intent, harness control, older context, model summaries, and untrusted evidence;
- exact approval identity, immutable argument previews, execution-time revalidation, and optional macOS LocalAuthentication step-up;
- trace/replay evidence for model turns, tool execution, fallback paths, run settlement, checkpoints, and future branch/replay work;
- watches/notifications as runtime-owned standing capabilities rather than sleeping conversation threads;
- AI-assisted engineering and review-speed thinking supported by Skeleton replay evidence.
