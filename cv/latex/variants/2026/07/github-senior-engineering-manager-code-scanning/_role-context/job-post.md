## Job Description Summary

GitHub is seeking a Senior Engineering Manager to lead and grow a distributed engineering team across Europe, the US, and Canada in the GitHub code scanning group.

The team develops the CodeQL detection engine, GitHub's semantic code analysis technology powering GitHub Code Scanning as part of GitHub Advanced Security. CodeQL analyzes code to detect security vulnerabilities and correctness errors early across ten supported languages including C/C++, C#, Go, Java, JavaScript/TypeScript, Kotlin, Python, Ruby, and Swift.

The team is responsible for how CodeQL understands code across these languages: extractors that produce CodeQL databases and libraries that model each language's structure and semantics. The team maintains consistent feature coverage and supports frequent language-version updates.
